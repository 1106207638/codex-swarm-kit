# 安装、更新和恢复

需要 Python 3.11+。安装器完全离线，不安装 Python、不下载模型、不接触登录信息；Codex 原生工具和模型权限必须在 Codex 内另查。Node 仅开发测试需要。

默认目录取进程 CODEX_HOME，未设置时为用户 ~/.codex。也可用 `--codex-home <绝对目录>` 显式指定；应与 Codex 实际使用的目录一致。安装器不替 Codex 修改环境变量。安装前结束需要使用旧入口的工作；未结束的台账继续用原版本，不复制到新电脑。

所有命令用本机实际 Python 运行 setup.py：

| 命令 | 作用 |
| --- | --- |
| `preview` | 校验包，显示目的地和拟合并规则；不写目标目录 |
| `install` | 显示计划、确认后安装；同内容再次运行无重复安装 |
| `doctor` | 核当前release文件摘要、规则指向和未完成事务；不调用模型 |
| `restore --transaction <安装回执ID>` | 回到该次安装之前的规则入口，保留用户后来增加的周边文字 |
| `resume --transaction <未完成ID>` | 持有进程锁后恢复明确的中断；遇未知变更拒绝覆盖 |

显式 `--yes` 表示已经审阅并同意本次动作，用于批处理；默认需要输入 y。`--codex-home` 可用于隔离测试。错误退出 2，正常退出 0，stdout 最后一行是结构化 JSON；交互模式还输出可读预览。

预览展示本包受管块的前后内容，并把源清单和目标快照绑定到本次确认。确认后若源包或目标被改动，会要求重新预览。POSIX 新文件和含规则全文的日志私有创建，更新保留原规则文件权限；这部分仍需目标 Mac 实机复核。事务备份含该电脑的原有规则，只留在本机，不要把安装目录或备份当成分享包。

独立目录：`swarm-kit/releases/<版本>-<内容摘要>/` 保存不可变载荷；`swarm-kit/active.json` 保存release和当前Python/platform/codex_home。AGENTS.md 只新增/替换 CODEX-SWARM-KIT 块。config.toml、全局 agents、账户和已有台账均不修改。

更新：解压新包后同一目录再次 install。先完整校验清单，写新release，持久化事务备份，再更新 active.json，最后启用规则块。旧release保留，运行中代理不会热换。首次安装把规则块放在 AGENTS.md 开头，原有字节不改。回退把该块换回之前内容或移除该块，保留周边后来编辑；初次回退后留下 inactive 指针和空AGENTS也属于预期，不删文件。

事务记录在 `swarm-kit/transactions/<ID>/journal.json`，包含改前/改后字节与摘要。安装或恢复中断后不再启动新安装；先核对该进程已经停止，再 resume 指定ID。每个目标必须仍为记录的改前或改后值，第三种值表示其他程序或用户改过，必须人工对账。恢复前重核将启用的release；损坏或未知文件不能靠回退洗掉。不要改事务、删失败记录或强行覆盖以“修复”。

遇已有 CODEX-UNIVERSAL-ROUTER、AGENTS.override.md、未知归属/损坏块、符号链接或 Windows 重解析目录时停止自动安装。由用户明确安排迁移或选择干净 Codex 目录，不叠加两套调度规则。受管块被用户修改也停止自动更新/回退。

安装、更新和恢复期间，请不要同时编辑 AGENTS.md 或安装目录。安装器锁只协调本包安装进程；会在临时文件准备完成后、替换前再次检查原字节，发现变更就保留原文件并中止。最后一次比较与系统替换不是一个不可分割操作，因此不能保证拦住任意编辑器恰好在两者之间的写入。事务摘要用于发现意外改动，不提供发布者签名或抵抗有权限重写全部文件的攻击。压缩包来源仍须可信。文件权限、Mac Gatekeeper 和真实 Codex 能力属于目标机验收；本版本 macOS 待实机验证。
