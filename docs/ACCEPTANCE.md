# 验证范围

部署包 1.0.0，复用调度合同 3.5.0。当前验收基准为 Windows；macOS 明确待实机验证。

已覆盖的核心回归包括模型/强度限制、角色职责、失败历史、文件任务包、主线程续轮合同、大纲顺序和交接证据。安装器覆盖预览、重复安装、实际源码 CLI 安装/诊断/恢复、更新回退、外部改动检测、断点恢复、目录/符号链接冲突、清单完整性及并发安装锁。POSIX 文件权限用例在 Windows 上明确跳过。

双入口、白名单 ZIP、校验值与解压后 Windows 入口由交付流程单独验证。源码附带 verify.py 和测试，可以在新电脑复跑；本文件的测试覆盖说明不代替目标机的实际执行记录。

| 能力 | 范围与限制 |
| --- | --- |
| Windows 安装 | 实际 Python/命令入口；隔离目标，不改开发者生产配置 |
| macOS 安装 | 已提供 POSIX 入口；实机、Finder、权限、Gatekeeper 待验 |
| 子代理模型选择 | 依赖当前宿主原生工具、模型与effort；逐机验证 |
| 主线程换模/Goal | 保留已有合同与回归；目标机未经实际验证不得称可用 |
| 并发保护 | 安装器锁与最后字节复核；不控制任意编辑器，不是OS级CAS |
| 隐私 | 只分发白名单源码/通用说明；本地备份包含用户规则，应留在本机 |
| 效率 | 没有可推广的公平提速或费用收益结论 |

环境依据：[Python Windows 文档](https://docs.python.org/3/using/windows.html)、[Python macOS 文档](https://docs.python.org/3.11/using/mac.html)、[POSIX命令转义范围](https://docs.python.org/3.11/library/shlex.html)。宿主实际工具与模型以运行时声明为准。
